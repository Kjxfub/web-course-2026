# Лабораторная работа №3: Todo-list на JavaScript

**Что сделано:** Создан интерактивный планировщик задач на чистом JS и DOM-дереве. Реализовано добавление, удаление, отметка выполнения, счетчики и фильтрация задач по статусу без перезагрузки страницы.
**Как запустить:** Откройте файл `index.html` в браузере (вся логика работает в `script.js` и рендерится динамически).
