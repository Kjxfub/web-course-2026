# Лабораторная работа №5 — Игра Simon («Симон говорит»)

Веб-версия классической игры на память и последовательность в стиле ночного джаз-клуба с виниловой пластинкой, карточными мастями, подсказкой «Повторяй мелодию!», анимацией нот и звуковым сопровождением на Web Audio API (`AudioContext`)[cite: 12, 16].

## Что реализовано
- Игровое поле из 4 кликабельных секторов (`0–3`), кнопка **«Старт»**, отображение текущего уровня/раунда и статуса хода[cite: 12, 13, 14].
- Последовательная генерация шагов (`0–3`) с удлинением на 1 элемент в каждом следующем раунде и поочерёдной подсветкой секторов через `setTimeout`[cite: 12, 13, 14, 16].
- Блокировка кликов игрока во время показа последовательности и защита от «зависших» таймеров при перезапуске или ошибке[cite: 12, 14, 15, 16].
- Завершение игры при ошибке с выводом достигнутого уровня («Вы дошли до уровня N») до повторного нажатия **«Старт»**[cite: 13, 15].

## Как запустить
1. Откройте папку `task5` (внутри находятся `index.html`, `style.css`, `script.js` и `README.md`)[cite: 16].
2. Запустите `index.html` в браузере (двойным кликом или через Live Server в VS Code).
